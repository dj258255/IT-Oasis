실시간 자막 경로를 만들면서 갈림이 셋 있었습니다. 셋 다 **한쪽을 고르면 다른 쪽을 내주는** 자리였습니다.

---

## 1. 하트비트는 설정만 주면 조용히 꺼집니다

WebSocket 연결이 60초쯤에 끊기는 것을 프록시 타임아웃으로 진단하고, 서버가 주기적으로 하트비트를 보내게 했습니다.

```java
registry.enableSimpleBroker("/topic")
        .setHeartbeatValue(new long[] {25000, 25000});   // 이것만 주면
```

**안 나갑니다.** 하트비트는 스케줄러가 보내는 것이라, `TaskScheduler` 를 같이 주지 않으면 **설정값만 남고 프레임은 안 나갑니다.**

```java
registry.enableSimpleBroker("/topic")
        .setHeartbeatValue(new long[] {25000, 25000})
        .setTaskScheduler(heartbeatScheduler());          // 이게 있어야 나간다
```

로그도 안 남고 예외도 안 납니다. **설정을 읽으면 켜져 있는 것으로 보입니다.**

> 스케줄러를 빼면 시험 3개가 깨지도록 고정했습니다.
> 조용히 꺼지는 것은 **되돌려서 깨지는지 확인**해야 켜져 있다고 말할 수 있습니다.

25초로 잡은 이유는 프록시 타임아웃 60초의 절반보다 짧아야 **한 번 놓쳐도 살아남기** 때문입니다. 너무 짧으면 연결 수만큼 프레임이 늡니다.

---

## 2. STT 와 LLM 은 과금 단위가 달라서 경로를 나눴습니다

자막과 회의 요약은 같은 전사에서 나옵니다. 한 경로에 두고 싶어지는데, **막히는 곳이 다릅니다.**

| | 과금 단위 | 무엇이 먼저 문제가 되나 |
|---|---|---|
| STT (자막) | **오디오 시간** | 지연. 5초 밀리면 화면의 음성과 안 맞는다 |
| LLM (요약) | **토큰** | 비용. 길이에 비례해 돈이 든다 |

**자막이 화면에 뜨는 경로에서는 LLM 을 안 부릅니다.** 정해진 용어 사전만 지납니다. 사전은 조회라 비용이 0 이고 시간도 밀리초입니다.

LLM 은 **지연을 허용하는 쪽**으로 보냅니다. 회의가 끝난 뒤의 요약과 검색 색인입니다.

> 같은 데이터를 쓴다고 같은 경로에 둘 이유는 없습니다.
> **막히는 곳이 다르면 나눠야 합니다.**

그리고 중간 자막(`partial`)은 저장하지 않습니다. 확정 전 조각이라 **저장하면 같은 말이 여러 번 남습니다.**

---

## 3. 모델을 붙이기 전에 모델 없는 방법부터 다 재 봤습니다

쌓인 자막을 검색하게 만들고 나서, 질문 형태에 약한 것이 남았습니다. 의미 검색(임베딩)을 붙이면 되겠다고 생각했는데, **붙이기 전에 모델 없이 갈 수 있는 데까지 가 보기로** 했습니다.

질의 30개(용어형 15 / 질문형 15)로 다섯 방식을 같이 쟀습니다. 아래는 **질문형 재현율**입니다.

| 방식 | 재현율 | |
|---|---:|---|
| 문자열 전체 매칭 | **0%** | 질의 전체를 부분문자열로 찾는다 |
| 토큰 매칭 | 43% | |
| **문자 2-gram** | **54%** | **모델 없음** |
| 임베딩 단독 | 60% | |
| 하이브리드(RRF) | **70%** | |

**어느 방식을 기준으로 잡느냐에 따라 같은 모델이 `0% → 70%` 도 되고 `54% → 70%` 도 됩니다.** 앞의 숫자는 모델의 기여가 아니라 **비교 대상이 약해서 나온 값**입니다.

```
54%p  모델 밖에서 얻는다
16%p  venv 857MB 를 상주시켜야 얻는다
```

렉시컬을 기본으로 넣고 **임베딩은 선택 의존성**으로 뺐습니다. 기본값은 끄기입니다.

### 이득이 어디서 왔는지 분해하기 전까지는 숫자일 뿐입니다

하이브리드가 2-gram 대비 개선한 5건을 열어 봤더니, **전부 어휘 겹침이 0%** 였습니다.

```
락 ↔ 자물쇠      커넥션 ↔ 연결      트래픽 없을 때 ↔ 아무 말도 안 오가면
```

**오탈자나 띄어쓰기 변형은 한 건도 없었습니다.** 의미 이해 덕이 맞습니다.

다만 한 건에서는 하이브리드가 임베딩 단독보다 **낮았습니다**(67% → 33%). 순위 병합이 렉시컬 오답을 끌어올려 임베딩 정답을 밀어냈습니다. **병합이 공짜가 아닙니다.**

가중치로 살릴 수 있지만 **질의 30개로 튜닝하면 그 30개에 과적합**이라 안 만졌습니다.

## 정리

셋 다 같은 모양입니다.

| | 안 하면 |
|---|---|
| 하트비트에 스케줄러를 같이 준다 | 설정은 켜져 있고 프레임은 안 나간다 |
| 과금 단위가 다르면 경로를 나눈다 | 지연을 지켜야 하는 쪽이 비용을 기다린다 |
| 모델 전에 베이스라인을 잰다 | 모델이 한 일과 비교 대상이 약해서 생긴 차이를 못 가른다 |
