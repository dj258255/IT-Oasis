## 왜 직접 만들었나

예전에 Velog를 쓰면서 블로그를 운영했었는데, 쓰다 보니 아쉬운 점들이 하나둘 생기더군요.
카테고리 구조를 제 입맛에 맞게 잡고 싶었는데 기존 플랫폼에서는 그게 쉽지 않았습니다.
이것저것 찾아보다가 결국 "그냥 내가 직접 만드는 게 제일 빠르겠다"는 결론에 도달했습니다.

## 기술 스택 선택

### Astro

정적 사이트 생성기를 여러 개 비교해봤는데, Astro가 딱이었습니다.

- **Zero JS by default**: 블로그에 무거운 런타임은 필요 없으니까요.
JS 번들 걱정 없이 순수한 HTML로 떨어지는 게 마음에 들었습니다.
- **Island Architecture**: 필요한 곳에만 인터랙티브 컴포넌트를 얹을 수 있어서 유연합니다.
검색이나 다크모드 토글 같은 부분에만 JS를 쓸 수 있습니다.
- **Content Collections**: 마크다운 기반 글 관리가 깔끔합니다.
프론트매터 타입 체크까지 해주니까 오타 같은 실수도 잡아줘서 좋습니다.

### 배포

배포는 GitHub Pages를 쓰고 있습니다.
Push만 하면 자동으로 빌드/배포가 되니까, 이 부분은 딱히 신경 쓸 게 없습니다.
정적 사이트라 CDN 캐싱도 잘 되고 응답 속도도 빠릅니다.

## 마무리

직접 만든 블로그라 이것저것 자유롭게 기능을 붙일 수 있는 게 가장 큰 장점입니다.
앞으로도 필요한 기능이 생기면 바로 추가할 생각입니다.
이 블로그의 코드는 GitHub에 공개되어 있으니, 궁금하신 분은 편하게 둘러보셔도 됩니다.
