# 손그림 다이어그램

포트폴리오·블로그의 다이어그램을 엑스칼리드로우 느낌으로 그린다.
엑스칼리드로우가 손그림을 그릴 때 쓰는 라이브러리가 rough.js 라, 그걸 직접 쓴다.

글자는 손글씨 폰트를 안 쓴다. 한글을 지원하는 손글씨 폰트가 마땅치 않고,
도형이 손그림이면 글자는 또렷한 편이 읽기 낫다. 당근 기술블로그 그림도 같은 조합이다.

```
cd tools/diagrams && npm install
node gen-<이름>.mjs ../../public/uploads/project/pay/diagrams/<이름>.svg
node build-all.mjs                 # 전부 다시 만든다
```

`seed` 를 좌표에서 뽑아 고정했다. 같은 그림을 다시 만들어도 획이 똑같이 나온다 —
안 그러면 커밋마다 전체 SVG 가 바뀌어 diff 가 쓸모없어진다.
