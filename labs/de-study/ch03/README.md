# DE 공부 4편 실습: 멱등한 적재와 지터

```bash
python idempotent_load.py
python backoff_jitter.py            # none, full, equal 세 방식 비교
```

## idempotent_load.py

쇼핑몰 주문 3건으로 일일 매출(`daily_sales`)을 적재한다. 10/1 매출은 30,000 + 12,000 = 42,000원이다.

| 경우 | 결과 |
|---|---|
| append를 두 번 | 10/1 행이 두 개(합치면 84,000원) |
| 파티션 덮어쓰기를 두 번 | 10/1 행 하나, 42,000원 |
| 트랜잭션 없이 지운 직후 죽음 | 10/1 행이 사라짐 |
| 트랜잭션 안에서 지운 직후 죽음 | 롤백되어 42,000원이 남음 |

## backoff_jitter.py

클라이언트 1,000개가 0초에 동시에 실패하고, 서버는 30초 뒤 살아난다. 백오프는 1초에서 시작해 두 배씩, 상한 60초. 종류마다 `random.seed(1)`로 고정해서 어디서 돌려도 같다.

| 방식 | 죽어 있는 동안 재시도 | 살아난 뒤 1초 최대 요청 | 마지막 클라이언트 성공 |
|---|---|---|---|
| none(지터 없음) | 4,000건 | 1,000건(31초) | 31초 |
| full jitter | 5,539건 | 44건(34초) | 88초 |
| equal jitter | 5,000건 | 76건(51초) | 59초 |
