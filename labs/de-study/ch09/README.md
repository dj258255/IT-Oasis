# DE 공부 10편 실습: coordinated omission

```bash
python coordinated_omission.py
```

서버는 요청 하나를 1ms에 처리하고 5.0~6.0초에 1초 동안 멈춘다. 목표 부하는 10ms마다 1건(초당 100건), 10초.

| 부하 방식 | 기록 건수 | p50 | p99 | p99.9 | max |
|---|---|---|---|---|---|
| closed loop(응답 받고 다음 요청, 밀린 요청은 건너뜀) | 902 | 1.0 | 1.0 | 991.0 | 991.0 |
| closed loop + 보정(expected interval로 빠진 요청 채움) | 1001 | 1.0 | 891.0 | 981.0 | 991.0 |
| open loop(10ms마다 보냄, 보내기로 한 시각부터 잼) | 1000 | 1.0 | 920.0 | 1001.0 | 1001.0 |
