# DE 공부 2편 실습: Bronze, Silver, Gold

쇼핑몰 상품 조회 로그 1만 건(사용자 5명, 0.1초 간격)에 중복, 잘못된 가격, 순서 뒤바뀜을 섞어 Bronze에 그대로 넣고, Silver에서 정리하고, Gold에서 사용자별 1분 평균 가격으로 집계한다.

```bash
python medallion.py               # 정상
python medallion.py --no-dedup    # Silver에서 중복 제거를 빼먹은 버그
```

기대 결과(시드 고정이라 어디서 돌려도 같다)

| | Bronze | Silver | Gold 조회 수 합계 |
|---|---|---|---|
| 정상 | 10,034행 | 9,980행 | 9,980 |
| `--no-dedup` | 10,034행 | 10,007행 | 10,007 |

- Bronze 10,034행 = 원본 1만 건 + 두 번 들어온 34건(300번째마다)
- 잘못된 가격은 원본 20건(500번째마다)이고, 그중 7건(1,500번째마다)은 두 번 들어와 Bronze에 27행이다
- Silver 9,980행 = 10,034 − 잘못된 가격 27행 − 남은 중복 27행

해 볼 것: `--no-dedup`으로 Gold를 만든 뒤 Bronze만 남아 있다고 치고 고친 Silver로 다시 만들어 본다.
