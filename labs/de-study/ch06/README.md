# DE 공부 7편 실습: pool과 중복 실행

```bash
python pool_limit.py
python duplicate_trigger.py
```

## pool_limit.py

외부 API를 부르는 태스크 50개. API는 동시 5건까지 1초에 처리하고 넘친 요청에 429를 준다고 가정한다. 429를 받은 태스크는 2초 뒤 다시 시도한다. 1초 단위 시뮬레이션이라 결과가 항상 같다.

| pool | 걸린 시간 | API 호출 | 429 |
|---|---|---|---|
| 50 | 19초 | 275 | 225 |
| 20 | 13초 | 125 | 75 |
| 10 | 11초 | 75 | 25 |
| 5 | 10초 | 50 | 0 |

## duplicate_trigger.py

같은 이벤트가 0초, 1초, 7초에 세 번 전달될 때 도는 run 수.

| 장치 | run |
|---|---|
| 없음 | 3번 |
| `max_active_runs=1` | 3번(차례로) |
| 이벤트 키로 run_id | 1번 |
